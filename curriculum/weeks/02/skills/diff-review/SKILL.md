# 1. Find problems

Input: the request, diff, and relevant code.

1. Inspect the change for bugs, regressions, and unmet requirements.
2. Check adherence to SOLID principles and look for performance opportunities.
3. Search for opportunities to introduce more design patterns.
4. List concerns and improvements with file references and expected benefits.
5. Suggest what should be fixed or refactored.

Review only; do not edit files or submit a PR review.
