# Handoff: Weeks 1–4 to Production

## Review Before Week 5
Students have explored a small idea at home, built a fresh app in VS Code, used one sustained terminal agent on an Excalidraw fork, and coordinated agents on an open-ended build. Review their repositories for working behavior, context maps, reusable procedures, checkpoints, checks, and explanations of what they trusted or corrected. Record incomplete criteria individually.

## Decide What Carries Forward
The Week 4 application may continue if it fits the production objectives, or the student may start a new application. It is not necessarily a Python/SQL application. Carry forward the engineering methods even when starting a new repository.

[Week 5](05/homework.md) establishes one working UI → API → database slice, an architecture decision, API contract, relational schema, and initial migration. Do not assume Week 4 produced those artifacts. [Week 7](07/homework.md) adds a data-preserving migration and PostgreSQL verification.
