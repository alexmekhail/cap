## Lab Instructions: Capstone Delivery
### Objective
Present your Production-Grade Cloud Application and demonstrate Architectural Sovereignty.

### Steps
1. **The Demo:** Ensure the deployed Vercel frontend correctly interfaces with the Cloud Run backend, performing a live, end-to-end demonstration of data ingestion and visualization.
2. **The Narrative:** Deliver a presentation featuring a 'Prompt Case Study': Show the initial naive code the AI generated (the 'Before'), the specific boundary-setting prompt you used (e.g., 'Refactor this to use the Strategy Pattern instead of hardcoded if/else chains'), and the final robust architecture (the 'After').
3. **The Log Highlight:** Select the best prompt log from your `docs/prompt-logs/` folder to present to the cohort.

### Deliverable
Final presentation and a complete, production-ready repository.
