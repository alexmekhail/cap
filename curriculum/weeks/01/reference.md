# Week 1 Student Reference

## Before Class
Have a GitHub account, VS Code, and your chosen paid agent with VS Code and terminal access. You are expected to know how to run a project, use branches, read Python/JavaScript, and debug a basic error. Tool installations and account billing vary: use your provider's current instructions and verify both interfaces before homework.

## Watch for These Patterns
- What did the speaker build first, and what changed?
- What did they give the AI besides a request?
- How did they decide the result was correct?
- Which failure caused them to change their workflow?
- What still requires their attention?

## At-home Readiness Check
Create or fork a repository → open it in VS Code → ask the agent for a small change → inspect the change → run it → try the terminal interface → commit and push to your own repository. Keep credentials and private data out of the work.

Your assignment is in [homework.md](homework.md). Save observations rather than trying to discover the perfect prompt.
