# Week 1 Homework: Get Ready and Try Something

## Purpose
Confirm your setup and become comfortable using AI to make something. This is an exploratory at-home attempt, not the start of the Week 2 project.

## Preparation
Bring your own GitHub account and paid agent access with both VS Code and terminal support. Check that your subscription actually enables both; a web-chat subscription alone is not proof. Follow your selected provider's setup instructions and record the tool/version you used. Use public or synthetic data and keep credentials out of prompts and commits.

## Work Plan (5–10 hours)
1. **Setup (1–2h):** Verify you can open a repository in VS Code, interact with the agent, use its terminal interface, run code, and push a branch to GitHub.
2. **Explore (2–4h):** Create a small new repository or fork a small public one. Try to build or change something of your choosing. Success is useful; a well-documented failed attempt also counts.
3. **Investigate (1–2h):** Revisit a confusing result and try another approach. Preserve evidence of what you tried.
4. **Reflect and submit (1–2h):** Write the field report below and make the repository easy to inspect.

## Field Report
In `docs/prompt-logs/week-01.md`, answer:
- What did you try to build or change, and which speaker's example influenced you?
- Which tools did you use? Did VS Code and terminal access both work?
- What worked surprisingly well?
- What failed or remained confusing? What did you try next?
- What questions do you want answered in Week 2?

## Submission
Push your work to your GitHub repository or fork. Put setup/run instructions, the report link, and a screenshot or short demo link in its README. If you use a PR, target your own repository, not the upstream project. Share the repository/PR link with the instructor before the next session. Never submit credentials or payment details.

## Assessment
| Criterion | Weight |
|---|---|
| Meaningful attempt and setup evidence | 30% |
| Specific, honest observations and investigation | 40% |
| Thoughtful questions connected to the experience | 30% |

Working software is not required this week. Record setup blockers early; the field report replaces the later structured evidence log.
