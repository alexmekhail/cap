# Week 3 Presenter Notes

Follow `talk-outline.md`: 75m instruction, 45m demonstration, 30m hands-on, 30m debrief/homework.

## Opening
“Last week you inspected between small changes. Today we move into the terminal and configure one agent to carry a larger task forward while we supervise its checkpoints. Longer running does not automatically mean better.”

## Context Discovery
“Your first task in an unfamiliar repository is to establish what is true. Ask for files and symbols, then inspect them. Save a small map of the relevant architecture and decisions. Use a skill to repeat the exploration procedure; use project instructions to describe the environment and constraints.”

## Control Modes
“In the loop means you decide between steps. On the loop means you define the outcome, checks, limits, and checkpoints. You still step in when evidence is missing or the task changes.” Show a repeated failure and ask whether continuing is justified.

## Demo and Practice
Use the local fixture. Show real failing checks, constrained implementation, and an independent rerun. Have students write a resume brief, then continue from it. Explain which information would become essential in a much larger repository.

## Excalidraw Briefing
“Your homework is deliberately larger: choose tabs/workspaces or selection-linked comments. The goal is a substantial change in an existing architecture, supported by context files, skills, checkpoints, and tests. You have 5–10 hours; report unfinished criteria honestly.” Compare the acceptance criteria and ask students to identify their first mapping question.
