# Orchestration and Harnesses

- Coordinate responsibilities and verify the combined result.

---

# Agent Contracts

- Purpose, inputs, outputs, tools, ownership, context, checks, and stops.
- A persona is not an execution contract.

---

# Three Harnesses

- Script-driven: explicit Python stages.
- Instruction-driven: a detailed workflow playbook.
- Hybrid: supervisor-generated helper code with continued oversight.

---

# Connections

- Dependencies and shared interfaces.
- Ownership boundaries and evidence-backed handoffs.
- One designated integration responsibility.

---

# Supervision

- Set retry/time/usage limits.
- Review generated coordination code.
- Independently run acceptance checks.

---

# The Hard Build

- Build a paint app or an equivalent challenge.
- Define the product, use a harness, demonstrate coordination.
- Continuation into Week 5 is optional; see homework.md.
