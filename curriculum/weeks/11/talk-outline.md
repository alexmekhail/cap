# Week 11: AI-Enabled SWE Interviews

## Talk Outline: Proving Your Sovereignty
### Technical Deep Dive (75m)
- **The Collaborative Coding Interview:** Talking through your prompt strategy live.
- **The AI System Design:** Designing systems *with* an AI agent as a collaborator.
- **The Prompt Audit:** Reviewing broken AI code and explaining *why* the prompt failed.

## Lab Instructions: Mock Interviews
### Objective
Successfully complete an AI-augmented technical interview.

### Steps
1. **Pair Up:** Pair with a peer or mentor.
2. **The Prompt Audit:** Interviewer provides a 50-line Python snippet simulating an API endpoint that contains a specific vulnerability (e.g., SQL injection via string formatting, or an Insecure Direct Object Reference (IDOR)).
3. **The Defense:** Identify the vulnerability. Formulate a specific prompt to instruct the AI to refactor the code using secure patterns (e.g., parameterized queries or an ORM like SQLAlchemy), and explain the prompt engineering constraints you utilized.
4. **The Log:** Document the feedback from your mock interview in `docs/prompt-logs/week-11.md`.

### Deliverable
Completion of the mock interview and a reflection document.
